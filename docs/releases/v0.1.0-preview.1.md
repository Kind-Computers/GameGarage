Game Garage by Kind Computers is a compact Windows utility suite with a RAM/CPU
data-path check and Windows integrity and maintenance tools.

This first public preview targets **Windows 11 x64 with English-language
Windows**. Extract the complete ZIP and open `GameGarage.exe`; no separate
.NET runtime installation is required. The application requests administrator
access and the preview is unsigned.

- A compact interface centers **Verify System**, with warm arcade colors, a
  brief pixel effect, and next steps based on the selected checks.
- Position-dependent RAM patterns, seed/complement pairs, supported scalar/SIMD
  coverage, and final readback improve what each sweep verifies.
- Runs report cancellation, incomplete coverage, errors, detected issues, and
  repairs separately. A memory mismatch does not identify a physical component.
- Windows file integrity uses SFC; Windows image and drive checks use the
  installed Windows tools. Repairs require confirmation; drive optimization
  is selected initially and can be deselected. It executes only when you choose
  **Verify System**.
- Source is MIT licensed. Runtime licenses and per-file checksums are in the ZIP;
  `SHA256SUMS.txt` provides the download checksum.

The included RAM check is a basic diagnostic, not exhaustive hardware
certification. Additional operating systems, translated command output,
saved-run comparisons, background operation, and code signing are future work. See the README and
release validation record for current capabilities and measured evidence.
