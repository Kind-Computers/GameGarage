# Security reports

For a potential vulnerability, use GitHub's private reporting form under
[Security advisories](https://github.com/Kind-Computers/GameGarage/security/advisories/new).
If private reporting is unavailable, open an issue requesting a private contact
without including vulnerability details. Ordinary bugs belong in Issues.

Include the Game Garage version, Windows build, reproduction steps, and impact.
Do not attach secrets or personal information. This preview runs with elevated
permissions, so command execution and unsafe memory access receive particular
review attention.

Security fixes target the most recent preview. No support response time is
promised. See the release notes for known limitations.
